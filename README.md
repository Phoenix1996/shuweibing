# 鼠卫兵

Windows 原生阴阳师窗口管家，0.2 预览版。C++17 + Win32 + 系统 Common Controls；无浏览器壳、后台服务和额外运行时安装。

## 运行

打开 `dist/0.2/鼠卫兵.exe`。默认是 580×410 个逻辑像素的紧凑面板，随系统 DPI 缩放。桌面快捷方式会指向该文件，移动项目后需更新快捷方式。

1. 游戏路径默认优先识别 `K:\Netease\yys\launch.exe`，可点“选择”更改。填写启动数量与间隔后点击“逐个启动 / 多开”。
2. 默认选中全部识别到的游戏窗口，主面板仅显示已选数量。窗口按进程名识别，默认筛选 `onmyoji;YysLauncher`，排除零尺寸和工具辅助窗口。
3. 需要选取部分窗口、修改进程筛选或启动参数时，点“窗口 / 设置”展开。识别不到时，点“添加窗口”，在 3 秒内切换到游戏窗口。可以再次收起。
4. 默认锁定长宽比例，修改宽或高会联动另一项。取消锁定后可填写新比例，再勾选锁定。宽高是游戏内容区像素尺寸，不含标题栏与边框。点“应用尺寸”生效。
5. 选择屏幕，点“自动排列”：从右上角向下排满当前列，再向左扩展；窗口间距 8 像素，保持填写的尺寸，整屏放不下时提示调小尺寸或减少选择。
6. 不透明度 100% 完全不透明，20% 最透明。点击应用后生效。
7. “隐藏 / 显示”操作勾选窗口。退出时会显示由鼠卫兵隐藏的窗口；隐藏记录跨程序重启保留。
8. “恢复布局”恢复本次会话首次修改前的位置、大小和透明度。
9. 最小化或点击“后台”进入托盘。双击托盘图标或右键“打开鼠卫兵”恢复；右键“退出程序”或窗口关闭按钮真正退出，并显示由鼠卫兵隐藏的游戏窗口。

## 适用范围

- 多开采用正常间隔启动；游戏的启动器或客户端如果限制单实例，此功能不能保证多开成功。尚需当前游戏版本实测。
- 建议游戏使用窗口模式；全屏、无边框或客户端强制比例可能限制大小调整。尺寸调整和排列采用异步请求，客户端可能重设自身窗口。
- 若游戏权限更高，窗口操作可能被系统拒绝。程序默认使用普通用户权限，会提示失败原因。
- 没有读写游戏内存、关闭客户端互斥量、账号输入或键鼠自动操作。
- 原布局记录仅保留本次程序会话；隐藏窗口记录保留到下次启动，窗口身份用进程创建时间核验，避免误操作复用的窗口句柄。

## 配置与稳定性

配置在 `%LOCALAPPDATA%\ShuWeiBing\settings.dat`，备份在 `settings.dat.bak`。写入临时文件、刷新落盘，再原子替换；校验失败时尝试有效备份，否则使用默认设置。

隐藏恢复记录在同目录的 `hidden.dat`，保存窗口句柄、PID 和进程创建时间，不保存账号、密码或游戏数据。程序不上传数据。

## 开发

项目路径：`L:\code\shuweibing`。源文件：`src/main.cpp`，资源：`src/resources.rc`，原创图标：`assets/mouse-guardian.png`。

使用 Zig 0.15.2 的 C++ 编译器构建：

```powershell
./src/build.ps1 -Zig '你的便携 Zig 路径\zig.exe'
```

构建生成 `dist/0.2/鼠卫兵.exe`。配置恢复、布局边界、比例联动、面板布局和自身测试窗口的 Win32 操作可用内置测试验证：

```powershell
Start-Process './dist/0.2/鼠卫兵.exe' -ArgumentList '--self-test','L:\code\shuweibing\.build\tests' -Wait
Get-Content './.build/tests/test-results.txt'
```

内置测试不操作游戏窗口。`--smoke-test` 显示管理界面并在约 4.5 秒后自动退出。

`--diagnose 输出文件路径` 只读导出默认游戏窗口的识别结果。当前验证结果见 [验证记录](验证记录.md)。
