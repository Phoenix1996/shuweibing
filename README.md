# 鼠卫兵

Windows 原生阴阳师窗口管家，0.3 预览版。C++17 + Win32 + 系统 Common Controls；无浏览器壳、后台服务和额外运行时安装。

## 运行

退出当前鼠卫兵，再打开 `dist/0.3/鼠卫兵.exe`。默认是 580×410 个逻辑像素的紧凑面板，随系统 DPI 缩放。桌面快捷方式会指向该文件，移动项目后需更新快捷方式。

1. 游戏路径优先读取运行中的客户端，也检查已保存路径、安装记录和本地磁盘的常见目录。点“查找 → 自动读取”刷新；找到多个启动器时可选择。点“扫描所选文件夹”后台扫描至三层子目录，跳过目录链接，范围最多 256 个目录、6000 个目录项，按 3 秒预算限制遍历；建议直接选择游戏安装文件夹。仍可点“选择”手动指定启动器。填写数量与间隔后点击“启动 / 多开”。
2. 默认选中全部识别到的游戏窗口，主面板仅显示已选数量。窗口按进程名识别，默认筛选 `onmyoji;YysLauncher`，排除零尺寸和工具辅助窗口。
3. 需要选取部分窗口、修改进程筛选或启动参数时，点“窗口 / 设置”展开。识别不到时，点“添加窗口”，在 3 秒内切换到游戏窗口。可以再次收起。
4. 默认锁定客户端比例 1113:627（约 16:9），宽 980 时高为 552。修改宽或高会联动另一项；这是比例规则，不是尺寸预设。取消锁定后可填写新比例，再勾选锁定。宽高是游戏内容区像素尺寸，不含标题栏与边框。点“应用尺寸”生效，已有配置保留。
5. 选择屏幕，点“自动排列”：从右上角向下排满当前列，再向左扩展；窗口间距 8 像素。按实际外框计算并只移动，保持窗口当前大小。短暂等待客户端响应后核验位置；重复点击不会提交新的尺寸。整屏放不下时提示先应用较小尺寸或减少选择。
6. 不透明度 100% 完全不透明，20% 最透明。点击应用后生效。
7. “隐藏 / 显示”操作勾选窗口。退出时会显示由鼠卫兵隐藏的窗口；隐藏记录跨程序重启保留。
8. “恢复布局”恢复本次会话首次修改前的位置、大小和透明度。
9. 最小化或点击“后台”进入托盘。双击托盘图标或右键“打开鼠卫兵”恢复；右键“退出程序”或窗口关闭按钮真正退出，并显示由鼠卫兵隐藏的游戏窗口。
10. 展开“窗口 / 设置”可切换“清晰启动”，默认开启。启动游戏时，通过此次启动专用的 `__COMPAT_LAYER=HIGHDPIAWARE` 环境标记请求游戏自行处理 DPI，避免 Windows 位图拉伸。不改注册表或全局环境变量。只对新启动的游戏及其正常继承环境的子进程生效，已有游戏需退出后重新启动。若游戏不适应该模式，可取消勾选后再启动。
11. 底部显示当前权限状态。普通权限时提示建议以系统管理员身份运行，并提供“管理员启动”按钮：点击后保存设置、显示 Windows UAC 提示，接受后重新打开本程序；取消时继续运行当前程序。游戏以管理员运行时，鼠卫兵也需相同权限。已是管理员时显示对应状态。
12. 老板键默认 **Ctrl + Alt + H**，全局生效：按一次隐藏已选的可见游戏窗口，并收起鼠卫兵；再次按恢复同一批窗口及原来可见的面板。不会显示此前已隐藏的窗口，也不改变游戏尺寸。展开“窗口 / 设置”，点击快捷键输入框按下自定义组合，勾选“启用”并点“保存快捷键”；“停用”可释放快捷键。支持 Ctrl/Alt/Shift 组合和 F1–F11；普通字母需要 Ctrl 或 Alt，F12 为系统保留。占用时提示更换，原快捷键继续有效。已隐藏窗口也可点击“显示”或退出程序恢复。

## 客户端下载

建议使用 **阴阳师-MuMu模拟器专版**。点击“查找 → 官方下载”，打开用户提供的[阴阳师官方下载页面](https://yys.163.com/zmb/)。安装完成后点击“自动读取”，或扫描所选安装文件夹。鼠卫兵不会自动下载、安装或替换游戏。

## 适用范围

- 多开采用正常间隔启动；游戏的启动器或客户端如果限制单实例，此功能不能保证多开成功。尚需当前游戏版本实测。
- 建议游戏使用窗口模式；全屏、无边框或客户端强制比例可能限制大小调整。尺寸调整采用异步请求；排列只移动并有限次数核验实际位置，客户端持续重设位置时会报告未稳定。
- 若游戏权限更高，窗口操作可能被系统拒绝。程序默认使用普通用户权限，会提示失败原因。
- 没有读写游戏内存、关闭客户端互斥量、账号输入或键鼠自动操作。
- 原布局记录仅保留本次程序会话；隐藏窗口记录保留到下次启动，窗口身份用进程创建时间核验，避免误操作复用的窗口句柄。

## 配置与稳定性

配置在 `%LOCALAPPDATA%\ShuWeiBing\settings.dat`，备份在 `settings.dat.bak`。写入临时文件、刷新落盘，再原子替换；校验失败时尝试有效备份，否则使用默认设置。

隐藏恢复记录在同目录的 `hidden.dat`，保存窗口句柄、PID 和进程创建时间，不保存账号、密码或游戏数据。程序不上传数据。

## 开发

项目路径：`L:\code\shuweibing`。源文件：`src/main.cpp`，资源：`src/resources.rc`，原创图标：`assets/mouse-guardian.png`。

使用 Zig 0.15.2 的 C++ 编译器构建：

```powershell
./src/build.ps1 -Zig '你的便携 Zig 路径\zig.exe'
```

构建生成 `dist/0.3/鼠卫兵.exe`。配置恢复、布局边界、比例联动、面板布局和自身测试窗口的 Win32 操作可用内置测试验证。完整验证脚本同时编译无 DPI 清单的专用测试程序，验证实际子进程启动方式：

```powershell
./src/test.ps1 -Zig '你的便携 Zig 路径\zig.exe'
```

内置测试不操作游戏窗口。`--smoke-test` 显示管理界面并在约 4.5 秒后自动退出。

`--diagnose 输出文件路径` 只读导出默认游戏窗口的识别结果、实际外框、客户区、屏幕工作区和 DPI 模式。当前验证结果见 [验证记录](验证记录.md)。

`--discover 输出文件路径` 只读导出自动发现的启动器路径。老板键使用系统 RegisterHotKey，不安装键盘钩子，不常驻轮询按键；目录扫描仅在用户点击时运行。
